# 🎓 EduTrack

EduTrack is a modern **student and class management system** designed with a clean, modular architecture.  
It’s built on **.NET 9**, **Entity Framework Core**, and **Avalonia UI** to support cross-platform desktop environments.

---

## 🚀 Project Goals

- 📦 **Clean Architecture:** Maintain clear separation between application layers.  
- ⚙️ **Extensibility:** Modular design to easily add features (attendance, grading, etc.).  
- 💡 **Cross-Platform:** Same codebase runs on Windows, macOS, and Linux via Avalonia.  
- 🔬 **Testability:** Structured unit and integration testing from day one.  
- 🎯 **Maintainability:** Follows domain-driven patterns and modern .NET practices.

---

## 🕕 Development Philosophy

This project follows **Agile** and **Domain-Driven Design (DDD)** principles to ensure clarity, adaptability, and long-term maintainability.

### Why it’s beneficial

📈 **Incremental progress** – each milestone results in a functional, testable application.  
🔁 **Continuous feedback** – enables validation of database structures, bindings, and user interfaces before increasing complexity.  
💾 **Solid foundation** – ensures Entity Framework setup, migrations, and data layers are stable and reliable.  
🚀 **Scalability** – once core features are stable, subsequent modules integrate seamlessly.
